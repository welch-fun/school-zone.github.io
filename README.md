# School Zone

A free static school-tools website with a hidden `/duckz/` arcade.

## Included

- Calculator
- Study timer
- Random picker
- Word counter
- Duckz 3-column responsive game grid
- Animated brown-framed game overlay
- Duck Dash
- Memory
- Duck Pong
- Click Duck
- Math Rush
- Reaction

## GitHub Pages

The repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml`.

In the repository's **Settings → Pages**, choose **GitHub Actions** as the source. GitHub Pages will then deploy the site from the `main` branch.

The expected URLs are:

- `/` — School Zone
- `/duckz/` — Duckz arcade

No build system or npm install is required.
